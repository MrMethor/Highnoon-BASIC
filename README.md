# [Highnoon](https://www.mobygames.com/game/42397/high-noon/)
A text-based video game from 1970.
Most likely the original code with few modifications in order to work with [Vintage BASIC](http://www.vintage-basic.net/download.html).
Originally designed and programmed by Chris Gaylo, Syosset H.S. 9/12/1970
